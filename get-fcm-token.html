🔔 FCM Token Generator

Generate a Firebase Cloud Messaging token to test push notifications for your Airbnb API.

⚠️ Before you start: You need Firebase Web configuration values from your Firebase Console.

📋 Step 1: Get Your Firebase Config

  1. Go to Firebase Console
  2. Select your project
  3. Click the gear icon ⚙️ → Project Settings
  4. Scroll to "Your apps" section
  5. Click the Web icon (</>) or select existing web app
  6. Copy the firebaseConfig object

📋 Step 2: Get Your VAPID Key

  1. Same page → Click "Cloud Messaging" tab
  2. Scroll to "Web Push certificates"
  3. Click "Generate key pair" if not exists
  4. Copy the Key pair value (starts with "B...")

📋 Step 3: Update Configuration Below

Open this file in a text editor and replace the values in the <script> section (lines 150-157 and line 163):

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",           // ← Replace this
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123"
};

const VAPID_KEY = 'YOUR_VAPID_KEY';  // ← Replace this

📋 Step 4: Generate Token

📋 Step 5: Register Token with Backend

Once you have the token, register it with your backend:

POST http://localhost:3000/api/v1/push-tokens
Authorization: Bearer YOUR_AUTH_TOKEN
Content-Type: application/json

{
  "token": "PASTE_YOUR_FCM_TOKEN_HERE"
}

📋 Step 6: Test Notification

Send a test notification:

POST http://localhost:3000/api/v1/push-tokens/test
Authorization: Bearer YOUR_AUTH_TOKEN

You should receive a notification in this browser! 🎉
